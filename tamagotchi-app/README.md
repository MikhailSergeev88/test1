# 🎮 Тамагочи - Виртуальный питомец

Интерактивное веб-приложение в формате тамагочи с возможностью запуска в браузере и интеграции с Telegram.

## 📋 Описание

Веб-приложение представляет собой игру, где пользователь получает виртуального питомца и ухаживает за ним: кормит, играет, лечит, укладывает спать и т.д. Задача игрока — поддерживать ключевые показатели питомца на высоком уровне, чтобы он рос и развивался.

## ✨ Ключевые функции

### Регистрация и профиль
- Автоматическая регистрация при первом запуске
- Экран профиля с информацией о питомце (имя, возраст, уровень)

### Главный игровой экран
- Анимированное изображение питомца (5 стадий роста)
- Индикаторы состояния:
  - ❤️ Здоровье: 0–100%
  - 🍖 Сытость: 0–100%
  - 😊 Счастье: 0–100%
  - ⚡ Энергия: 0–100%
  - 🧼 Гигиена: 0–100%

### Взаимодействие с питомцем
- 🍖 Кормление (повышает сытость)
- 🎾 Игра (повышает счастье, тратит энергию)
- 🛏️ Сон (повышает энергию)
- 💊 Лечение (повышает здоровье)
- 🧼 Гигиена (повышает счастье и гигиену)

### Система развития
- 5 стадий роста: яйцо → малыш → подросток → взрослый → пожилой
- Визуальное изменение внешнего вида при переходе на новый уровень
- Достижения и награды за выполнение задач

### Временная механика
- Постепенное снижение показателей со временем
- Реальное время (не игровая симуляция)

### Уведомления
- Push-уведомления в браузере
- Уведомления через Telegram-бота при критическом состоянии

### Интеграция с Telegram
- Telegram Bot API для уведомлений
- Запуск игры через бота (команда /start)
- Отображение прогресса через команду /profile

## 🚀 Быстрый старт

### Предварительные требования
- Node.js >= 18
- MongoDB (локально или Atlas)
- npm или yarn

### Установка

1. **Клонируйте репозиторий**
```bash
cd tamagotchi-app
```

2. **Установите зависимости**
```bash
# Установить зависимости для всех пакетов
npm install

# Frontend
cd frontend && npm install

# Backend
cd backend && npm install
```

3. **Настройте переменные окружения**

Создайте файл `backend/.env` на основе `backend/.env.example`:
```bash
cp backend/.env.example backend/.env
```

Отредактируйте `backend/.env`:
```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://localhost:27017/tamagotchi
TELEGRAM_BOT_TOKEN=your_bot_token_here
JWT_SECRET=your_jwt_secret_here
FRONTEND_URL=http://localhost:3000
```

4. **Запустите приложение**

В режиме разработки (оба сервера одновременно):
```bash
npm run dev
```

Или по отдельности:
```bash
# Frontend (порт 3000)
cd frontend && npm run dev

# Backend (порт 5000)
cd backend && npm run dev
```

5. **Откройте приложение**
- Фронтенд: http://localhost:3000
- Backend API: http://localhost:5000/api
- Health check: http://localhost:5000/health

## 📱 Использование Telegram бота

1. Создайте бота через [@BotFather](https://t.me/botfather)
2. Получите токен бота
3. Добавьте токен в `backend/.env`
4. Запустите backend
5. В Telegram найдите вашего бота и отправьте `/start`

### Команды бота
- `/start` - Начать игру или войти
- `/profile` - Показать статус питомца
- `/help` - Справка

## 🎨 Стадии роста питомца

| Стадия | Уровень | Описание |
|--------|---------|----------|
| 🥚 Яйцо | 0 | Начальная стадия |
| 👶 Малыш | 1-4 | Милый детёныш |
| 🧒 Подросток | 5-9 | Активный подросток |
| 🧑 Взрослый | 10-19 | Полностью развит |
| 👴 Пожилой | 20+ | Мудрый старец |

## 🏆 Достижения

- **Первый уровень** - Достигните уровня 1
- **Опытный владелец** - Достигните уровня 5
- **Мастер заботы** - Достигните уровня 10
- **Здоровяк** - Поддерживайте здоровье на 100%

## 🔧 Разработка

1. Соберите фронтенд: `npm run build`

#### Бэкенд (Heroku/DigitalOcean)
1. Настройте переменные окружения
2. Убедитесь, что MongoDB доступен
3. Задеплойте приложение
